# Clipboard HTML Content to Markdown

Converts HTML contents of Clipboard to markdown. MacOS only.

Demo:

[Demo Video](https://share.zight.com/o0ul6Je7)

This is useful when copying content from a website and pasting it into other apps that don't parse clipboard contents as HTML, like ChatGPT and Claudee.

Two commands are available:

- `clipboard-html-to-markdown`: Copies the markdown to the clipboard
- `clipboard-html-to-markdown-paste`: Pastes the markdown to the active application
